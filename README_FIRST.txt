KUCHI KAGURA — 帰らずの里 / EXPLORATION HORROR GAME

村を探索し、屋敷・井戸・蔵の三枚の鎮め札を北の社へ返してください。
祭壇で境の鍵を受け取り、南の門から脱出します。
写真・かんざし・草履、握り飯・団子、神楽鈴を使って怪異の足を止められます。
既存の .blend / GLB / 1Kテクスチャ / 8種の骨格アニメーションも保持しています。
プレイ中は外部CDN・APIを使用しません。

Windows:
1. リポジトリから取得した場合は、最初にNode.jsを用意し npm ci を実行してください。
2. PLAY.bat でゲーム本編を起動します。PREVIEW_ONLY.bat でも同じ本編が開きます。
3. 再生成する場合は BUILD_AND_PREVIEW.bat を実行してください。
4. OPEN_IN_BLENDER.bat で編集用 .blend を開けます。

バッチはご指定の C:\Program Files\Blender Foundation\Blender 5.2\blender.exe を最初に探し、
見つからない場合はPATH上のBlenderを探します。
制作・ブラウザ検証はLinux / Blender 4.3.2で実施しました。
Windows / Blender 5.2.2そのものはこのクラウドから実行していません。

反応: idle / walk / alert / chase / search / lament / feed / ritual
写真・かんざし・子どもの草履 → lament
おにぎり・団子 → feed
神楽鈴 → ritual

WASD:移動 / マウス:見回す / Shift:走る / C:しゃがむ / E:調べる / F:灯り
1〜6:品物選択 / G:投げる / R:鈴 / Tab:手記と地図 / EscまたはP:一時停止
スマートフォンは左の移動パッドと右の見回し・アクションボタンを使います。
拾得・反応・祭壇の進行を自動保存します。ゲームは通常の脱出と三つの思い出を手向けた結末を持ちます。
本編は / 、元のキャラクター確認画面は /character.html です。
起動・操作・検証のコマンドは README.md、ゲーム構成は GAME_DESIGN.md を参照してください。
主人公モデルは含みません。POV用両腕は独立したGLBとして後から追加する設計です。
