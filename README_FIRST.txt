KUCHI KAGURA — 帰らずの里 / EXPLORATION HORROR GAME

村を探索し、屋敷・井戸・蔵の三枚の鎮め札を北の社へ返してください。
祭壇で境の鍵を受け取り、南の門から脱出します。
写真・かんざし・草履、握り飯・団子、神楽鈴を使って怪異の足を止められます。
写真の左の眼鏡の人物と右の短髪の人物を、別々の追跡者として本編へ配置しています。
新二体の .blend / GLB / 2Kテクスチャ / 8種の骨格アニメーションを同梱し、旧女性型怪異のモデルも保持しています。
白い半袖シャツ・緑のランヤード・濃紺パンツを造形し、見えない背面や脚は創作で補完しています。
実名や実在組織のロゴはモデルに使用しません。
プレイ中は外部CDN・APIを使用しません。

Windows:
1. リポジトリから取得した場合は、最初にNode.jsを用意し npm ci を実行してください。
2. PLAY.bat でゲーム本編を起動します。PREVIEW_ONLY.bat でも同じ本編が開きます。
3. 新二体を再生成する場合は BUILD_AND_PREVIEW.bat を実行してください。旧怪異は npm run build で再生成できます。
4. OPEN_IN_BLENDER.bat は眼鏡モデルを開きます。引数 cropped で短髪、original で旧怪異を開けます。
新二体の編集用ファイルは export/pursuer_glasses.blend と export/pursuer_cropped.blend です。
新二体の再生成は npm run build:references（BlenderをPATHに設定）が必要です。
新二体は40ボーンで、両手の指も曲げて供物を拾う・食べる動作を行います。旧怪異の20ボーンは保持しています。

バッチはご指定の C:\Program Files\Blender Foundation\Blender 5.2\blender.exe を最初に探し、
見つからない場合はPATH上のBlenderを探します。
制作・ブラウザ検証はLinux / Blender 4.3.2で実施しました。
Windows / Blender 5.2.2そのものはこのクラウドから実行していません。

反応: idle / walk / alert / chase / search / lament / feed / ritual
写真・かんざし・子どもの草履 → lament
おにぎり・団子 → feed
神楽鈴 → ritual

WASD:移動 / マウス:見回す / Shift:走る / C:しゃがむ / E:調べる / F:灯り
1〜6:品物選択 / G:投げる / R:鈴 / Tab:手記と地図 / EscまたはP:一時停止
スマートフォンは横向きで、左の移動パッドと右の視点パッドを同時に操作します。
左パッド下の行動ボタンは、歩く→走る→屈むをタップごとに切り替えます。「道具」で所持品を開きます。
右パッド下は「調べる・手向ける」。視点の速さを抑えています。縦向きと道具欄を開いている間は一時停止します。
対応ブラウザは開始・再開時に全画面化します。ツールバーが残る端末では「ホーム画面に追加」して起動してください。
拾得・反応・祭壇の進行を自動保存します。ゲームは通常の脱出と三つの思い出を手向けた結末を持ちます。
本編は / 、三体の切り替え・顔や衣装の細部・8動作の確認画面は /character.html です。
起動・操作・検証のコマンドは README.md、ゲーム構成は GAME_DESIGN.md を参照してください。
主人公モデルは含みません。POV用両腕は独立したGLBとして後から追加する設計です。
